# Librería Online 📚

## 📖 Descripción del Proyecto
Librería Online es un proyecto web diseñado para simular una tienda o catálogo de libros en línea. Su propósito principal es ofrecer una interfaz gráfica atractiva, intuitiva y amigable donde los usuarios puedan explorar una colección de títulos literarios, consultar información de distintos autores y contar con un medio de contacto directo.

Originalmente construido con una arquitectura del lado del servidor, el proyecto ha sido convertido a un formato completamente **estático (HTML puro, CSS y JavaScript)**, lo cual permite un rendimiento ultrarrápido y compatibilidad para ser alojado de forma gratuita y eficiente mediante **GitHub Pages**.

## ✨ Características Principales
- **Diseño Moderno y Responsivo**: Interfaz construida para adaptarse a dispositivos móviles, tablets y pantallas de escritorio.
- **Catálogo de Libros**: Visualización en tabla de los diferentes libros disponibles, incluyendo título, tipo y precio.
- **Registro de Libros**: Formulario estático simulado para la captura de detalles exhaustivos sobre nuevos títulos (ID, publicación, precio, avances, ventas, notas y contrato).
- **Catálogo de Autores**: Visualización de los autores destacados junto a sus datos básicos.
- **Registro de Autores**: Formulario simulado para registrar la información de los escritores (nombre, dirección, teléfono, etc.).
- **Sección de Contacto**: Un formulario para que los visitantes de la plataforma puedan enviar sus dudas y comentarios.
- **Despliegue Sencillo**: Estructurado para subirse fácilmente a un entorno estático sin necesidad de bases de datos o intérpretes de backend.
